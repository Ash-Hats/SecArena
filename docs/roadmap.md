# SecArena Development Roadmap

- **Phase 0 — Foundation:** FastAPI, React, PostgreSQL, configuration, and migrations. Complete.
- **Phase 1 — Authentication and RBAC:** JWT, Argon2id, Student/Instructor/Admin roles. Complete.
- **Phase 2 — Dashboards:** student and instructor portals. Complete.
- **Phase 3 — Lab and event management:** declarative labs, hints, publishing, training events. Complete.
- **Phase 4 — Browser-based simulation engine:** persistent sessions, safe command parser, virtual Linux scenario, scoring, detections, flags, timeline, and student UI. Complete for the initial Linux scenario.
- **Next:** simulated web rules (SQL injection, XSS, IDOR), virtual network actions, broader scenario authoring, richer analytics, and defensive rule authoring.
